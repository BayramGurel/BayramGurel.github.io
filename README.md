# Verhuisd naar luchtinbeeld.nl

Het luchtkwaliteitsdashboard heet nu **Lucht in beeld** en staat op **https://luchtinbeeld.nl/**.

Deze site stuurt bezoekers door: gedeelde links (met stof, dag, uur, plek en kaartpositie) en widgets op andere websites blijven werken. Is luchtinbeeld.nl ooit onbereikbaar, dan gaat het naar https://luchtinbeeld.vercel.app/.
